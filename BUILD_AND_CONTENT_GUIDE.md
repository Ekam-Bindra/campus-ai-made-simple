# Project preparation and sharing guide

Campus AI Made Simple is an independent learning project. Its public deliverables are a seven-lesson notebook, helper code, a beginner walkthrough, and a record of observed results. No video is required to use or share it.

## Start learning

1. Read [LEARNING_GUIDE.md](LEARNING_GUIDE.md).
2. Open the notebook using the Colab button in [README.md](README.md).
3. Enter your own API key in the hidden prompt and run cells in order.
4. Save a learning log based on actual outputs and tool traces.

## Current verification scope

Lessons 1–4 have live outputs supplied by the author. Lessons 5–7 have local tool and scripted SDK checks, with live Gemini verification pending. See [EVALUATION.md](EVALUATION.md), [VERIFICATION.md](VERIFICATION.md), and [the local execution report](Lesson_5_6_7_Test_Report.md).

Expected answers in the guide are pass criteria, not fabricated live outputs. Local checks do not establish live model selection or generated-answer quality. Keep pending labels until genuine live runs meet the criteria.

## Prepare your own version for sharing

1. Review answers against the fictional records and inspect tool traces.
2. Keep source IDs, prompts, and non-sensitive observations in your results log.
3. Update testing status only when new evidence supports it.
4. Clear notebook outputs if you introduced private information; never commit a key.
5. Check README links, the cover image, and the notebook from the public repository page.

The project can be shared while checks remain pending if its description accurately states that status. A recorded demonstration is optional.
